# The Quiet Watch concept-image provenance

These four images are art-direction references for the Starship Cabin 2.0 vision. They are not gameplay screenshots and are not intended to be shipped as runtime textures.

All four were generated specifically for this project on 2026-09-03 using OpenAI's built-in image-generation system. No input or reference images were supplied.

| File | Prompt direction |
| --- | --- |
| `first-question.jpg` | A warm private starship cabin framing a true-black, layered galactic star field with no nearby planet or station. |
| `great-weather.jpg` | The same shelter-versus-vastness composition facing a dimensional ringed gas giant, storms, ring shadow, and moons. |
| `harbour-ten-thousand-lights.jpg` | A warm cabin docked beside a colossal original orbital station with repeating habitat lights, depth tiers, and tiny service craft. |
| `blue-morning.jpg` | A warm cabin above an Earth-like dawn with a distant peaceful formation of original ships. |

Shared constraints:

- original generic science fiction
- no franchise designs or motifs
- no logos, text, UI, or watermarks
- no combat or weapons
- no characters or cat
- no primitive-placeholder or glossy toy-plastic appearance

The images define intended mood, composition, shelter, scale, and lighting. Quest implementation must reconstruct those perceptions within the measured frame budget rather than attempting to reproduce offline-render fidelity directly.

## M1 runtime provenance

The M1/M1.1 `First Question` playable adds no third-party runtime art, audio, fonts, or data. Its sky, galactic structure, stars, dust, drift, and comet are generated by the original project shader in `Assets/Shaders/QuietWatchStarWindow.shader`. M1.1 reuses the repository's proven V3 principles—dense point stars and a broad power-law brightness range—inside the new camera-ray-anchored implementation; it does not import Claude's beta/New Hope runtime code or any external asset. The selector, lifecycle, transitions, persistence, captures, and telemetry are original project code. Existing cabin geometry, materials, and procedural ambience remain governed by the repository's MIT license and IP boundary.

## M2–M5 review-slice runtime provenance

The multi-vista review build adds no third-party runtime art, textures, audio, fonts, or data. The station kit, ring systems, service craft, and both ship families are original procedural meshes generated by `Assets/Editor/QuietWatchExteriorBuilder.cs`. Blue Morning, Great Weather, and the authored planetary rings use original project shaders in `Assets/Shaders/QuietWatchBlueWorld.shader`, `QuietWatchGasGiant.shader`, and `QuietWatchRings.shader`. Existing Unity primitive sphere topology is used only as the carrier mesh for original procedural planet shading. None of Claude's beta/New Hope runtime assets or code are imported.

## M5 exterior-art benchmark provenance

The `2.0.0-m5-art-benchmark` pass adds no third-party runtime art or texture source. The command ship, two escort families, station sector, twelve LOD FBXs, five shared PBR maps, and editable `ArtSource/QuietWatchVisualBenchmark.blend` are generated specifically for this repository by `tools/blender/build_quiet_watch_benchmark.py` using Blender 4.5 LTS. Hull plating, normal, metallic/smoothness, ambient-occlusion, and emissive maps are deterministic original outputs of that script. Unity material/import/LOD integration is implemented by `Assets/Editor/QuietWatchArtAssetBuilder.cs`. The assets use no franchise names, silhouettes, logos, supplied references, purchased meshes, texture libraries, or external generative assets.
